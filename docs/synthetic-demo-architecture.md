This is an explicitly labeled guided simulation, not a real multi-user account system. Production JWT authorization remains unchanged. Simulation actions enforce persona/step boundaries for correctness; these are not a security boundary against someone changing their own browser memory. Circular obligations remain visible while zero transfers are suggested. Portfolio content explains simulated registration/login, explicit invitation acceptance, equal/unequal expenses, settlement, notifications and disabled recovery.
